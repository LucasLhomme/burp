# Burp Suite Security Workshop

> **Web application penetration testing and security assessment laboratory.**

## Overview
Practical security exercises focused on discovering, exploiting, and remediating common web application vulnerabilities:
- Web vulnerability analysis with Burp Suite Proxy and Repeater
- Testing for OWASP Top 10 flaws: SQL Injections, Cross-Site Scripting (XSS), CSRF, IDOR, and privilege escalation
