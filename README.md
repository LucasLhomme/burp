> **Practical laboratory on web application penetration testing using PortSwigger's Burp Suite**, auditing OWASP Top 10 security vulnerabilities.

---

## 🔍 Auditing Areas

- **HTTP Traffic Interception:** Request manipulation and parameter tampering via Burp Proxy.
- **Vulnerability Vectors:**
  - SQL Injections (SQLi)
  - Cross-Site Scripting (Reflected & Stored XSS)
  - Cross-Site Request Forgery (CSRF)
  - Broken Access Control & IDOR (Insecure Direct Object References)
- **Defensive Recommendations:** Input sanitization, parameterized queries, and CSRF token protections.
